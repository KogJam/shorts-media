# shorts-media

Automated English fact Shorts for YouTube: offline voice (Kokoro), Pixabay stock clips, Noto 3D emoji,
rendered with Python + ffmpeg and scheduled through Metricool. See `WORKFLOW.md`.

The `videos` branch only holds the current batch of rendered MP4s (temporary hosting for Metricool).

Credits: stock footage from Pixabay (Pixabay Content License), emoji images from Google Noto Emoji (OFL/Apache 2.0),
voice model Kokoro-82M (Apache 2.0), CMU Pronouncing Dictionary.
